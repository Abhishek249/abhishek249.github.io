# Abhishek Jain — AI Platform Portfolio

Personal portfolio and public AI-platform roadmap for Abhishek Jain.

## Updating the roadmap

The roadmap is intentionally kept in `index.html` so progress is visible and easy to update after each course or project milestone. Change a step's class to `complete` or `current`, update its status label, and adjust the percentage in `.progress-track`.

## Local preview

Open `index.html` directly or serve the directory with any static file server.

## Deployment

This repository is designed for GitHub Pages at `https://abhishek249.github.io/`.
