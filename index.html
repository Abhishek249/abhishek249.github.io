The problem

Quality is what keeps agents out of production

Coding agents got good enough to write real systems this year. What did not arrive with them is a way to know the output is correct at the speed agents produce it. In LangChain's 2026 practitioner survey, quality — accuracy, consistency, adherence to spec — is the single largest barrier to putting agents in production, named by a third of teams. Tracing has near-universal adoption at 89%; systematic offline evaluation sits at 52%.

That gap is the work I do. Not prompting, not framework tourism — the unglamorous layer that decides whether agent output ships: golden datasets, deterministic metrics, failure-mode analysis, and validation gates that run without a human in the loop.

Flagship

Gavel

MCP-native evaluation harness for agent-built data pipelines

MITPython 3.11+

The LLM decides when to validate. Gavel decides pass or fail.

A coding agent building a data pipeline can tell you it succeeded. It cannot tell you the rows are right. Gavel is a local MCP server the agent calls to get a verdict it does not control: a declarative sandbox pins the system components, the golden and candidate datasets, the metric rubric, and the evidence required for a pass — then a deterministic engine returns a structured report the agent must answer to.

The shipped taxi example: duplicate rows injected into an otherwise clean dataset. Row count, key uniqueness and fare total all fail, and the agent gets the specific checks that failed rather than a bare rejection.

What it does that a test suite doesn't

Catches silent success. Live adapters for Postgres, Dagster and the workflow orchestrator collect evidence from the running system, so a green orchestration run that quietly produced missing or wrong data still fails. That failure mode is invisible to ordinary pipeline monitoring, and it is the one that reaches customers.

Makes evaluation declarative. Sandboxes are YAML, so the rubric is reviewable in a pull request instead of living in someone's notebook. Six MCP tools cover sandbox discovery, golden-vs-candidate validation, live evidence collection, and geospatial validation — the agent chooses when to call; it never chooses the verdict.
